# v1.3.2 字体实机检查

2026-11-18，Steam / MAGES 版，游戏窗口约 1896 × 1098。检查使用最终基线 -3 的字库；下面 `final_` 截图均来自这一版。

## 实机发现与修复

v1.3.1 虽然将标点换成了正文字体，但《等左括号的墨迹偏右，超出了游戏原有比例字符的取样宽度，实机只剩部分笔画。现在将前 640 格的普通字符墨迹放回原版横向范围，必要时仅收窄横向尺寸，保留文楷字形和统一基线。

[修复前的实际裁切画面](font_runtime_v1.3.2/before_clipped.png)可与下方括号样例对照。

字体生成器此前未限制单字绘制范围，负基线可能把笔画写入上一排字格。现在先清空画布，再逐格限制绘制范围；基线由 -7 改为 -3，为高字形和带圈数字留出顶部空间。全部普通字符均未触及字格上下边缘。
