# v1.3.3 全稿显示检查与原文校订

本轮对全部 886 个脚本、95,559 条记录执行原文对应、行号、动态变量、控制标签、异常空白、日文残留及标点检查。868 个脚本含文本，18 个原脚本没有文本记录。自动检查覆盖全稿；逐句语义校对和实机查看的覆盖范围另外记录，不能用“待校标记为 0”代替全稿质量保证。

## 已落地的修改

共修改 327 个脚本中的 937 行，各类别有重叠：

- 273 行原文对照改译，包括主客体颠倒、否定意思译反、漏译、冗长译注和事实单位误译。
- 632 行中文括号、问号、叹号统一为全角；按键变量、数学公式和原文英语保持。
- 21 行将学校负责人“学長”的错误译名“学长”改为“校长”。
- 12 行修正“回朔”为“回溯”。
- 清除结城台词中异常的连续全角空格，恢复被挤远的句尾标点。

可追溯修改见 [changes.jsonl](../localization/reviews/v1.3.3/changes.jsonl)，每项包含脚本、行号、日文、旧译、新译和修改原因。批量工具 `tools/apply_text_review.py` 校验旧稿和原文，拒绝控制标签变更；重放全部修改后与正式译稿逐字节一致，二次运行不产生修改。

## 原文校对范围

按修订前正文可见字符数至少 45 个筛出 442 条长对白，归并为 342 组日文与现译组合，逐组对照日文检查，并同步修改同文分支。记录见 [long_dialogue_review.jsonl](../localization/reviews/v1.3.3/long_dialogue_review.jsonl)。另外检查正文中两种语言均含数字、但数字序列不一致的 24 组文本，区别汉字数字、口吃、重排与实质数值差异，并修正扫描时发现的短句误译。

典型修改：

| 原文 | 原译问题 | 修订 |
| --- | --- | --- |
| 20世代もさかのぼれば | 回到二十多岁；凭空增加另一个陌生人 | 往上追溯二十代，你我可能有亲缘关系 |
| 電子の目がいかに節穴かをわからせてあげる | 被译成无法通过监控 | 让对方见识电子监控形同虚设 |
| 論理学 | 伦理学 | 逻辑学 |
| 私になぜか心を開いてくれていた | 敞开心扉的主客体颠倒 | 他愿意向我敞开心扉 |
| 10キロ四方 | 十平方公里 | 边长十公里的范围 |
| カウンタ | 反作用力 | 计数器 |
| 連続した世界としか知覚できない | 无法觉察连续世界 | 只能感知到连续世界 |

仍不能宣称 95,559 行全部完成逐句精校。既有 JF 待校标记清零只表示旧清单已处理；本轮仍发现原译错误，后续精校应继续对照原文。

- 实机记录另见 [text_runtime_v1.3.3.md](text_runtime_v1.3.3.md)。字符数量只用来筛选检查优先级，不能证明引擎中的像素宽度或全路线无溢出。
